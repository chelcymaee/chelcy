# Podcast reel edit

Follow `podcast-edit/RULEBOOK.md` exactly. It is the approved spec, and the reference result is `podcast-edit/IMG_0222_reel_9x16_v5.mp4`.

Non-negotiables:
1. Run `podcast-edit/tools/setup.sh` first (`WORK` = your scratchpad).
2. Transcribe the video, then **send the asset request list (rule book section 1) BEFORE editing**: players and characters, logos, articles and stats to screenshot, cards and products, and unsure captions, each with its reel timestamp, plus the upload link.
3. Target 30 minutes from receiving the assets to the finished reel.
4. Pass every QC check in rule book section 9 before sending. Audio must run to the last frame.
5. Never invent stats, headlines, cards or prices. Spoken words stay verbatim in captions.
